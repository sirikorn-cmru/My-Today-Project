## คำอธิบาย

เอกสารนี้รวม Test Case แบบ step-by-step (manual/black-box) ของทุก Feature ในหน้า Today Dashboard (Sprint 1) แปลงมาจาก Scenario `AC-001-01` ถึง `AC-001-07` ใน [[../acceptance-criteria#Sprint 1: Today Dashboard|acceptance-criteria.md]] เสริมด้วย edge case จาก `## Business Rules` ของ [[../../../01-requirements/01-spec/20260806-001-my-today-sprint1-today-dashboard|spec Sprint 1]] และ 1 Test Case เชิง integration จาก Step 2 ของทั้งสอง Persona ใน [[../../../01-requirements/user-journey|user-journey.md]] เนื่องจากยังไม่มีการตั้งค่า test runner อัตโนมัติในโปรเจกต์นี้ (ดู `CLAUDE.md` → Commands) ทุก Test Case จึงเป็นแบบทดสอบด้วยมือบน dev build จริง (`npm run dev`)

ทุกรายการด้านล่างอ้างอิง Mock Data ชุดทดสอบเดียวกันตามที่ระบุใน Business Rules ของ Sprint 1 ("ข้อมูลทั้งหมดในหน้านี้เป็น Mock Data ที่สร้างขึ้นสำหรับทดสอบ Dashboard เท่านั้น") — คอลัมน์ Test Data ด้านล่างสมมุติชุดตัวอย่างที่สอดคล้องกับสไตล์ของ seed data จริงในโค้ด (`src/data/seedTasks.ts`, `src/data/mockData.ts`) เพื่อให้ผู้ทดสอบมีค่าตัวอย่างที่ทดสอบได้จริง
