## แนวคิด/เป้าหมาย

พัฒนาตามแนวคิด Human-Centered Design เป้าหมายหลักคือให้ผู้ใช้เปิดระบบแล้วตอบได้ทันทีว่า **"วันนี้ฉันต้องทำอะไร"**

นี่คือ Sprint แรกของโปรเจกต์ ("My Today") ยังไม่มี Sprint ก่อนหน้ามาก่อน

## เทคโนโลยีและสถาปัตยกรรม

- React + TypeScript + Tailwind CSS
- ทำงานทั้งหมดฝั่ง Browser (client-side only) — ไม่มี Backend, ไม่มี PHP, ไม่มี MySQL, ไม่มี Server-side code, ไม่มี AI, ไม่มี API ภายนอกที่จำเป็นต่อการทำงานหลัก
- เก็บข้อมูลขนาดเล็ก (รายการภารกิจ) ด้วย LocalStorage
- เก็บไฟล์แนบด้วย IndexedDB
- รองรับ Mobile-first และ Responsive ตาม breakpoint มาตรฐาน

## Feature requirements / User stories

- ในฐานะผู้ใช้ ฉันต้องการเพิ่มภารกิจใหม่ได้ เพื่อบันทึกสิ่งที่ต้องทำ
- ในฐานะผู้ใช้ ฉันต้องการดูรายละเอียดของภารกิจที่มีอยู่ได้
- ในฐานะผู้ใช้ ฉันต้องการแก้ไขภารกิจที่มีอยู่ได้
- ในฐานะผู้ใช้ ฉันต้องการทำเครื่องหมายภารกิจว่า "เสร็จ" หรือ "ยังไม่เสร็จ" ได้
- ในฐานะผู้ใช้ ฉันต้องการลบภารกิจที่ไม่ต้องการแล้วได้
- ในฐานะผู้ใช้ ฉันต้องการเปิดหน้าแรกของระบบแล้วเห็นเฉพาะภารกิจที่ครบกำหนด "วันนี้" ทันที เพื่อให้รู้ว่าวันนี้ต้องทำอะไรโดยไม่ต้องค้นหาเพิ่ม
- ในฐานะผู้ใช้ ฉันต้องการแนบไฟล์ประกอบภารกิจได้ (ไม่บังคับ) เพื่อเก็บเอกสารที่เกี่ยวข้องไว้ด้วยกัน
- ในฐานะผู้ใช้ ฉันต้องการใช้งานระบบนี้ได้ดีทั้งบนมือถือและหน้าจอขนาดต่าง ๆ

## Business rules

1. แต่ละภารกิจ (Task) ต้องมี field ขั้นต่ำดังนี้:
   - ชื่อภารกิจ (title)
   - วันครบกำหนด (due date)
   - สถานะ (เสร็จ / ยังไม่เสร็จ)
   - ไฟล์แนบ (attachment) — ไม่บังคับ มีได้หรือไม่มีก็ได้
2. หน้าแรกของระบบ ("วันนี้") แสดงเฉพาะภารกิจที่วันครบกำหนดตรงกับวันปัจจุบันเท่านั้น
3. ลำดับการแสดงภารกิจในหน้า "วันนี้" เรียงตามลำดับที่ถูกเพิ่มเข้าระบบ (ยังไม่มี priority หรือการเรียงลำดับแบบอื่นใน Sprint นี้)
4. ข้อมูลรายการภารกิจเก็บด้วย LocalStorage และไฟล์แนบเก็บด้วย IndexedDB โดยทั้งหมดอยู่บนเครื่องผู้ใช้เท่านั้น ไม่มีการ sync ข้ามอุปกรณ์หรือบัญชีผู้ใช้
5. **Non-regression rule (มีผลกับ Sprint ถัดไปในอนาคต):** เมื่อมีการพัฒนา Sprint ถัดไป ต้องรักษาข้อมูลและฟังก์ชันที่มีอยู่จาก Sprint ก่อนหน้าให้ทำงานได้ครบถ้วน ไม่ทำให้ของเดิมพัง — กฎนี้ยังไม่มีผลย้อนหลังกับ Sprint 1 นี้ เนื่องจากยังไม่มี Sprint ก่อนหน้าอยู่จริง

## ขอบเขต (Scope)

### In scope (Sprint 1)

- CRUD ภารกิจ: เพิ่ม / ดู / แก้ไข / ทำเครื่องหมายเสร็จ-ยังไม่เสร็จ / ลบ
- Field ขั้นต่ำของภารกิจ: ชื่อภารกิจ, วันครบกำหนด, สถานะ, ไฟล์แนบ (ไม่บังคับ)
- หน้าแรก "วันนี้" แสดงเฉพาะภารกิจที่ครบกำหนดวันนี้ เรียงตามลำดับที่เพิ่มเข้าระบบ
- เก็บข้อมูลทั้งหมดในเครื่องผู้ใช้ (LocalStorage + IndexedDB) ไม่มี sync ข้ามอุปกรณ์/บัญชี
- UI แบบ Mobile-first และ Responsive

### Out of scope (เก็บไว้ทำใน Sprint ถัดไป)

- หมวดหมู่/ป้ายกำกับภารกิจ (category/label)
- ระดับความสำคัญ (priority) ของภารกิจ และการเรียงลำดับตาม priority
- บันทึกย่อ/รายละเอียดเพิ่มเติม (notes) ของภารกิจ
- หน้าดูภารกิจทั้งหมดนอกเหนือจากหน้า "วันนี้" (เช่น มุมมองปฏิทิน, รายสัปดาห์, รายเดือน)
- ระบบแจ้งเตือน (notifications)
- AI หรือ API ภายนอกใดๆ ที่จำเป็นต่อการทำงานหลักของระบบ
- Backend/Server-side ทุกชนิด (PHP, MySQL, server-side code ใดๆ)
