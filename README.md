## ระบบนี้คืออะไร

**My Today — One Life, One Workspace** เป็น *Personal Daily Workspace* บนเว็บ ที่ออกแบบให้เปิดมาแล้วตอบได้ทันทีว่า **วันนี้ต้องทำอะไร อะไรสำคัญ อะไรใกล้ครบกำหนด และอะไรเสร็จแล้ว**

จุดตั้งต้นไม่ใช่ "แอปจดงาน" อีกตัว — ปัญหาที่จับคือคนทั่วไปไม่ได้ขาดแอป แต่ข้อมูลชีวิตกระจัดกระจายอยู่ในหลายที่เกินไป My Today จึงจัดระเบียบรอบ **ชีวิตของคน** ผ่านแนวคิด **Life Area** (เช่น Study / Work / Finance / Family) แทนที่จะจัดรอบระบบขององค์กรใดองค์กรหนึ่ง ใช้ได้ทั้งนักศึกษา พนักงาน ครู ฟรีแลนซ์ และผู้ปกครอง

**ทำงานแบบ local-first** — ข้อมูลทั้งหมดเก็บอยู่ในเบราว์เซอร์ของผู้ใช้เอง (LocalStorage และ IndexedDB) ใช้งานได้เต็มรูปแบบแบบออฟไลน์ **โดยไม่ต้องสมัครบัญชี**

ความสามารถหลัก: Dashboard สรุปวันนี้ · จัดการงาน · ปฏิทินและตาราง · Timeline แบบ Now/Next/Later · จัดเก็บไฟล์แนบ · แจ้งเตือนใกล้ครบกำหนด · Quick Capture บันทึกเร็วเข้า Inbox ไว้จัดทีหลัง · Life Area และโปรไฟล์ส่วนตัว

ฟีเจอร์ที่ต้องเข้าสู่ระบบ (ไม่บังคับ ปิดไว้เป็นค่าเริ่มต้น):

- **Cloud Sync** — สำรอง/ซิงก์ข้อมูลข้ามอุปกรณ์ผ่าน Firebase Authentication + Cloud Firestore โดยผู้ใช้แต่ละคนเข้าถึงได้เฉพาะข้อมูลของตัวเอง (บังคับที่ [firestore.rules](firestore.rules) ไม่ใช่แค่ฝั่งหน้าจอ)
- **Smart Capture from Image** — ให้ AI (Google Gemini) อ่านรูป เช่น โปสเตอร์งาน แล้วเติมฟอร์มสร้างงาน/กิจกรรมให้อัตโนมัติ โดยผู้ใช้ต้องตรวจและกดบันทึกเองเสมอ

**เทคโนโลยี:** React 18 · TypeScript · Vite · Tailwind CSS · LocalStorage/IndexedDB · Firebase Auth + Firestore (ส่วนเสริม) · Vercel (โฮสต์ + Serverless Function สำหรับเรียก Gemini ฝั่งเซิร์ฟเวอร์)

## วิธีรันในเครื่อง

ต้องมี **Node.js 18 หรือ 20 ขึ้นไป** (ตามที่ Vite 5 กำหนด — เวอร์ชัน 19 ใช้ไม่ได้)

```bash
npm install
npm run dev
```

เปิด http://localhost:5173 — ใช้งานได้ทันทีโดยไม่ต้องตั้งค่าอะไรเพิ่ม ระบบจะใส่ข้อมูลตัวอย่างให้เองในครั้งแรก

### คำสั่งอื่น

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | รัน dev server (พอร์ต 5173) |
| `npm run build` | ตรวจ type ด้วย `tsc --noEmit` แล้ว build ไปที่ `dist/` |
| `npm run preview` | เปิดผลลัพธ์ที่ build แล้ว (พอร์ต 4173) |
| `npm run lint` | ตรวจโค้ดด้วย ESLint |
| `npm run test:rules` | ทดสอบกฎความปลอดภัยของ Firestore กับ Emulator — **ต้องมี Java 21 ขึ้นไป** |

### การตั้งค่าเพิ่มเติม (ไม่จำเป็นสำหรับการรันทั่วไป)

ฟีเจอร์ Smart Capture ต้องใช้คีย์ของ Google Gemini ซึ่งอยู่ฝั่งเซิร์ฟเวอร์เท่านั้น ดูตัวอย่างการตั้งค่าที่ [.env.example](.env.example) — คัดลอกเป็น `.env` แล้วใส่ค่าจริง (ไฟล์ `.env` ถูก gitignore ไว้แล้ว) ส่วนฟีเจอร์อื่นทั้งหมดทำงานได้โดยไม่ต้องมีคีย์ใดๆ
