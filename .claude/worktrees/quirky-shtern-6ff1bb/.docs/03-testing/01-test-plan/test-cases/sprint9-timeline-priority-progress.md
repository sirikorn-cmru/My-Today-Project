## คำอธิบาย

Test case ทั้งหมดในไฟล์นี้เป็น **manual/black-box** (ยังไม่มี test runner อัตโนมัติในโปรเจกต์ — ดู `CLAUDE.md`) ทดสอบด้วยมือบน dev build ที่รันจริง (`npm run dev`) แบ่งเป็น 3 กลุ่มตาม Feature Requirements ของ Sprint 9 บวก 1 test case เชิง integration ที่เดินตาม [[../../../01-requirements/user-journey|user-journey.md]]

**หมายเหตุเรื่องเวลา:** เนื่องจาก Timeline (Now/Next/Later) อ้างอิงเวลาปัจจุบันจริงของเครื่องผู้ทดสอบ (Business Rules ข้อ 1) Test Data ด้านล่างระบุเวลาโดยอ้างอิงกับ **เวลาปัจจุบันขณะทดสอบ (เรียกว่า T)** เช่น "T+30 นาที" แทนการระบุเวลานาฬิกาตายตัว ผู้ทดสอบต้องปรับเวลาจริงตอนสร้างข้อมูลทดสอบให้ตรงกับสูตรนี้
