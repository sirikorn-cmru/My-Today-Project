# 02 - Plan

เก็บเอกสาร **แผนการดำเนินงาน** ที่แปลงมาจากข้อกำหนดใน [[../01-spec/index|01-spec]] เช่น

- Roadmap / timeline ของโปรเจกต์
- การแบ่ง phase หรือ milestone
- ลำดับความสำคัญ (priority) ของแต่ละฟีเจอร์
- ทรัพยากรและระยะเวลาที่คาดว่าจะใช้

แผนในโฟลเดอร์นี้จะถูกแตกย่อยต่อเป็นงานที่ลงมือทำได้จริงใน [[../03-task/index|03-task]]

ตอนนี้ active แล้ว 1 ไฟล์:

- `project-plan.md` — สร้าง/อัปเดตผ่าน skill `project-plan-intake` (ดู `CLAUDE.md`) จัดกลุ่ม Sprint ทั้งหมดจาก [[../backlog|backlog.md]] เข้าเป็น Phase ระดับสูงตาม track ที่ `CLAUDE.md` section "Project purpose" กำหนด (ปัจจุบัน Phase 1 Version 1/Core และ Phase 2 Competition Track) พร้อมสถานะ roll-up — เวอร์ชันกระชับ ไม่มี timeline/milestone/dependency breakdown
